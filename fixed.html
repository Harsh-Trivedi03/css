Fixed Header on Scroll

The header is fixed at the top of the page, even as you scroll down.

Unlike sticky headers, a fixed header will stay in the same position on the screen, regardless of scrolling.

Here's how the position: fixed; property works:

1. The header is positioned relative to the viewport, not the parent element.

2. The header stays at the top (or wherever you set it) even when you scroll.

3. This is useful when you want certain elements, like navigation bars or toolbars, to stay in view all the time.

Use cases:

- Fixed headers are great for navigation menus or call-to-action buttons that should remain visible.

- They're used in toolbars or sticky notifications on websites, so the user can always access them.
